{% extends "demo/app_base.html" %} {% load static %} {% comment %} Enterprise Clinical Copilot — the application, behind the front door. The shell is a collapsible menu on the left and the conversation beside it. There is no patient rail. Patient selection lives in the ask bar as an `@` command, and the sidebar lists the threads those selections produced — one thread per patient, because a conversation is about exactly one patient. The menu carries three labels — New Conversation, Discover, Tools. Discover and Tools are placeholders, rendered `disabled` so that a control doing nothing cannot be mistaken for a feature that is broken. History is gone: there was a control that revealed the thread list, and a list a reader has to ask for is a list they have to know is there. Account actions are split. The user guide and the request count sit in the menu at the top right of the page — the same markup the front door uses, and the same script drives it, so the two menus cannot drift apart. Sign-out sits under the identity at the foot of the sidebar. The conversation is one continuous column. Turns are not cards and do not fold: each one is headed by the question that asked it, and the heading pins to the top of the scroll area while its own answer passes beneath it. {% endcomment %} {% block title %}Enterprise Clinical Copilot{% endblock %} {% block content %}
