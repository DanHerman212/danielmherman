# danielmherman

This repo serves as the front end for my personal website, which is a custom CMS written in Django.  Embedded within the repo are web applications that serve as front end for modern AI and ML applications


| Where to start | What it covers |
|---|---|
| **[Enterprise Clinical Copilot](docs/copilot/README.md)** | The clinician-facing front door: identity, session management, credits, and the presentation of the agent's answer with the evidence behind it. |
| **[Content management system](docs/cms/README.md)** | The personal site: articles, projects and an inbox, authored in the Django admin. |
| **[Architecture and infrastructure](docs/architecture/README.md)** | How both are built and where they run: the Django request path, the Google Cloud deployment, the security posture, and the copilot's path beyond this application. |
